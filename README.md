# Парсер эндуро-мотоциклов motocikl.by

Скрипт `parse_enduro_motocikl.py` скачивает первые 5 карточек эндуро-мотоциклов из каталога motocikl.by, открывает страницу каждого товара и сохраняет результат в CSV-файл.

## Запуск

```bash
python3 parse_enduro_motocikl.py
```

По умолчанию будет создан файл `enduro_motocikl.csv` в текущей папке. Его можно открыть в Excel, LibreOffice Calc или скачать с сервера как обычный CSV-файл.

## Настройки

```bash
python3 parse_enduro_motocikl.py \
  --url "https://motocikl.by/katalog/vse_tovary/mototsikly/enduro/" \
  --limit 5 \
  --output enduro_motocikl.csv
```

- `--url` — страница каталога.
- `--limit` — сколько первых мотоциклов парсить.
- `--output` — путь к CSV-файлу.
- `--pause` — пауза между запросами к страницам товаров, чтобы не перегружать сайт.

## Как данные разбиваются по категориям

В CSV всегда есть базовые колонки:

- `Название`
- `Цена`
- `Ссылка`
- `Изображение`

Характеристики со страниц товаров добавляются отдельными колонками в формате:

```text
Категория: Характеристика
```

Например: `Двигатель: Объем`, `Размеры: Высота`, `Трансмиссия: КПП`. Если на странице товара нет явного заголовка категории, характеристика попадает в категорию `Характеристики`.
